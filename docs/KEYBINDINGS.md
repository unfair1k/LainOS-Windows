# Keyboard shortcuts

The bindings below are taken from the included GlazeWM configuration.

| Action | Shortcut |
|---|---|
| Focus left / right / up / down | `Alt + H / L / K / J` or arrow keys |
| Move window left / right / up / down | `Alt + Shift + H / L / K / J` or Shift + arrows |
| Resize window | `Alt + U / P / O / I` |
| Enter resize mode | `Alt + R` |
| Pause / resume GlazeWM | `Alt + Shift + P` |
| Toggle tiling direction | `Alt + V` |
| Toggle floating window | `Alt + Shift + Space` |
| Toggle tiling | `Alt + T` |
| Toggle fullscreen | `Alt + F` |
| Minimize focused window | `Alt + M` |
| Close focused window | `Alt + Shift + Q` |
| Exit GlazeWM | `Alt + Shift + E` |
| Reload GlazeWM config | `Alt + Shift + R` |
| Redraw GlazeWM | `Alt + Shift + W` |
| Open Kitty | `Alt + Enter` |
| Next / previous active workspace | `Alt + S / Alt + A` |
| Recent workspace | `Alt + D` |
| Switch to workspace 1–9 | `Alt + 1` … `Alt + 9` |
| Move window to workspace 1–9 | `Alt + Shift + 1` … `Alt + Shift + 9` |
| Move workspace between monitors | `Alt + Shift + A / F / D / S` |

## Kitty shortcuts

| Action | Shortcut |
|---|---|
| New tab | `Ctrl + Shift + T` |
| Close tab | `Ctrl + Shift + W` |
| Next / previous tab | `Ctrl + Shift + Right / Left` |
| New window | `Ctrl + Shift + Enter` |
| Increase / decrease font | `Ctrl + + / Ctrl + -` |
| Reset font size | `Ctrl + 0` |
| Toggle fullscreen | `Ctrl + Shift + F` |

`Alt + Space` is not bound by GlazeWM; the included YASB config assigns it to the YASB quick launcher.

## YASB shortcuts

| Action | Shortcut |
|---|---|
| Open YASB quick launcher | `Alt + Space` |
| Open wallpaper gallery | `Ctrl + Alt + W` |

These shortcuts work while YASB is running. If another application uses the same shortcut, change one of the bindings in the YASB configuration.
