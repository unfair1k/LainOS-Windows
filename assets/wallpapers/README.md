# Wallpapers

The original Kitty wallpaper was named lain-room.jpg. The image itself was not available in the repository or cleared for redistribution, so this repository does not include a replacement or claim ownership of it.

To restore the original local setup, place your own licensed copy of that image at:

    %USERPROFILE%\.config\kitty\lain-room.jpg

Alternatively, put it in assets\wallpapers\lain-room.jpg before running setup.ps1; the setup script will copy it into Kitty's config folder if no local copy already exists.

The YASB wallpaper gallery uses this folder when present:

    %OneDrive%\Imagens\wallpaper\themes\monochrome

Otherwise, it uses:

    %USERPROFILE%\Pictures\Wallpapers

Add your own wallpapers to the selected folder. Only commit images you created or have permission to redistribute.
